# BEYOND DESTINATIONS — プロトタイプ

サステナブルツーリズム普及を目的とした体験予約プラットフォームのPoC。
ビルド不要の静的サイト(HTML/CSS/Vanilla JS)です。

## 起動方法

`index.html` をブラウザで直接開くだけで動作します。
ローカルサーバーを使う場合:

```
python3 -m http.server 8000
```

→ http://localhost:8000

## 画面構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ(ヒーロー/コンセプト/おすすめ体験/ビジョン導線) |
| `vision.html` | ビジョンページ(ステートメント/課題認識/本来の日本/仕組み) |
| `experiences.html` | 体験一覧(職人/農林水産業/サイクリングのカテゴリ絞り込み) |
| `experience.html?id=…` | 体験詳細(ギャラリー/価格内訳/スコア/現地集合明記) |
| `booking.html?id=…` | 予約フロー3ステップ(日時人数→予約者情報→ダミー決済) |
| `complete.html` | 決済完了(市町村シルエットが満ちていくアニメーション) |

## コード構成

- `js/i18n.js` — 日/英/仏の3言語辞書と切替(ヘッダーのJA/EN/FRボタン、localStorageに保存)
- `js/data.js` — 体験6件・市町村6件のデータ、SVG風景アート生成、市町村サステナブル度の進捗管理
- `js/main.js` — 共通ヘッダー/フッター描画と各ページのロジック
- `css/style.css` — デザイン(明朝体/白基調/深緑 `#2e5c44`・若草 `#7fa650`)

## 仕様上のポイント

- **旅行業法対応**: 全体験が現地集合・現地解散。宿泊・送迎関連のUIは一切なし
- **価格設計**: 体験単価 約3万円/人、地域還元80%・手数料20%を内訳表示
- **サステナブル・スコア**: CO2削減量(ダミー計算)+地域還元額から100点満点で表示
- **市町村サステナブル度**: 予約完了ごとに `人数 × (スコア/100) × 1.6pt` 上昇(localStorageに累積)。完了ページで市町村シルエットが下から満ちるSVGアニメーション

## プロトタイプとしての割り切り

- 決済はダミー(入力値は送信されません)
- 写真は実写の代わりにSVG生成の風景アート(本番では実写に差し替え)
- 市町村シルエットは抽象形状(本番では実際の市町村境界SVGに差し替え)
- Webフォント(Shippori Mincho / Cormorant Garamond)はGoogle Fonts経由。オフライン時はシステム明朝にフォールバック
