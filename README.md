# BEYOND DESTINATIONS — 海外の旅行会社向けデモ

岐阜のつくり手（職人・酒蔵など）の体験を、**海外の旅行会社が問い合わせ・予約する**ためのサイトの試作です。
説明資料（ブルビック決勝用・Tongali 3分ピッチ）に合わせ、「地域の人と海外の旅行会社を直接つなぐ」形にしています。
ビルド不要の静的サイト（HTML/CSS/Vanilla JS）です。

## 起動方法

```
python3 -m http.server 8765
```

→ http://localhost:8765

## 画面構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（旅行会社向けのヒーロー／数字／選ばれる理由／体験／予約の流れ／岐阜1.1%） |
| `experiences.html` | 体験一覧（体験のみ／貸切の1日 で絞り込み） |
| `experience.html?id=…` | 体験詳細（過ごし方・1日の流れ／含まれるもの／卸値） |
| `booking.html?id=…` | 空き状況の問い合わせ 3ステップ（旅の内容→御社の情報→確認）。準備中の体験は「関心の登録」 |
| `complete.html` | 受付完了（受付番号／このあとの流れ） |
| `vision.html` | 私たちについて（役割の図／これから／連絡先） |

## 商品と料金（資料と同じ数字）

- **美濃和紙**・**日本酒**：体験のみ（現地集合・現地解散）、2時間・最大3名、試験的な料金 1名 30,000円
- **酒蔵をめぐる1日**：岐阜駅 9:30 発 → 酒蔵 → 昼食 → 15:30 岐阜駅、車・通訳ガイドつき、2〜5名
  - 3名で 1回 384,000円（1名 128,000円）。付録A6・A7 と同じ計算（`js/data.js` の `bdDayQuote()` で人数から計算）
- **山奥のサウナ**・**千年の柿渋**：準備中（料金なし・関心の登録のみ）
- 担い手・地域への還元の表示は入れていない
- 料金はすべて旅行会社向けの卸値で、海外の旅行会社の手数料は含まない

## コード構成

- `js/i18n.js` — 英語（既定）／日本語の辞書と切替
- `js/data.js` — 商品データ、1日ツアーの料金計算、写真と出典、SVG風景アート
- `js/main.js` — 共通ヘッダー／フッターと各ページの処理
- `css/style.css` — デザイン（明朝体／白基調／深緑 `#2e5c44`・若草 `#7fa650`）
- `img/` — 写真（フリー素材のイメージ）

## 試作としての割り切り

- 問い合わせは送信されない（ブラウザの中で受付番号を作るだけ）
- 写真はWikimedia Commonsのフリー素材（CC BY-SA 4.0）。出典は詳細ページの写真下に表示。本番では実写に差し替える
- 写真が読み込めないときは、SVGの風景アートを表示
